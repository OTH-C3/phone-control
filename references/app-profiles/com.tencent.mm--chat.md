# com.tencent.mm · 聊天页（ChattingUI）

> 任务场景：搜索联系人 → 进会话 → 读聊天记录 → 发送一条消息。
> 只记录**跨机器不变的交互规律**，不含任何具体联系人或聊天内容。

## 经验分三类，一个文件里分开写

| 类别 | 回答什么问题 | 本页结论 |
|---|---|---|
| **① 平台特征** | 这页天生是什么样 | 原生 View，消息文字可读；标题栏与输入法候选**读不到** |

| **③ 已知陷阱** | 踩过的坑 | 标题读不到→靠头像 desc；置顶被折叠；同名联系人要分清 |

## ① 平台特征（这页天生是什么样）

- **渲染方式**：原生 View。一屏 dump 约 24 条元素、5 万字节级 XML，**消息文字读得到**。
- **消息文本**：纯文字消息给 `text`；图片/表情/语音/转账等给**占位文本**
  （`[图片]`、`[视频]`、`[表情]`、`[转账] 已收款`），**内容读不到**。
- **时间戳**：独立文本节点，可当分隔锚点。
- **会话标题栏**：**读不到**。标题是自定义 View，没有 `text` / `content-desc`。
- **头像**：有 `content-desc`，形如 `<联系人名>头像`（机主自己的头像 desc 是机主昵称）。
- **输入框**：`android.widget.EditText`；**有内容时**右侧才出现名为 `发送` 的
  `android.widget.Button`（空的输入框没有这个按钮）。
- **不可逆动作**：**发送**。发出即对对方可见（撤回是另一个手动动作）。

## ② 有效模式（该怎么做才对）

- **定位联系人**：点首页右上角搜索（`content-desc="搜索"`）→ 在搜索框输入**拼音**（ASCII，能进）→
  结果分「联系人 / 群聊 / 聊天记录」三块，点**联系人**块下那一行。
  **搜索框支持拼音匹配中文联系人**，这一步不需要能打中文。
- **读聊天记录**：进会话默认停在最新一条，用 `scroll_read.py --dir up` 往上读历史。
  纯文字对话拼接正常；图片刷屏时读到的多是 `图片` 占位行。
- **发消息**（顺序照抄）：
  1. 点输入框（`EditText` 的 bounds 中心），唤出键盘；
  2. 注入目标文案（**中文输入受限，见 `facts.md` F27**）；
  3. **`uiautomator dump` 读「发送」按钮的真实坐标**（不按截图估算）；
  4. **发送前核对**：dump 里 `EditText.text` 是否与目标文案**逐字一致**，会话是否是目标对象；
  5. 点「发送」，再 dump 一次确认输入框已空、消息已进入会话。
- **标题读不到时怎么确认对象**：① 看会话里的**头像 `content-desc`**
  （一对一会话只有一个对方头像 + 自己的头像）；② 截图看标题栏（视觉通道）；
  ③ 一对一会话没有群成员列表，群聊会有多个头像 desc。
- **输入法状态**：候选词/键盘只能**截图**看（**F29**）。

## ③ 已知陷阱（踩过的才写）

**陷阱 1 —— 会话标题栏读不到，容易误判"进错人了"**
- 现象：`probe.py` 里**找不到**会话标题那几个字，只有 `<联系人名>头像`。
- 原因：标题是自定义绘制，没暴露 `text` / `content-desc`。
- 做法：用**头像 `content-desc`** 判断当前会话对象，并**截图交叉确认**标题栏。
  收件人核对靠头像 + 截图；**内容核对靠 dump 读 `EditText.text`**。

**陷阱 2 —— 常聊的人可能不在可见会话列表里**
- 现象：首页前几屏看不到目标会话。
- 原因：置顶会话过多会被折叠成「折叠置顶聊天」→ 展开后是「N 个置顶聊天」入口，
  点它不一定平铺开，容易来回折叠、找不到人。
- 做法：**直接用搜索（拼音）**，比在列表里翻、点置顶可靠得多。

**陷阱 3 —— 中文输入的三种"看起来可行"**
- 现象：`input text "中文"` 报 `NullPointerException`；`input keyevent`（字母键码）只出英文候选；
  换输入法也一样；新版 Android 上 `cmd clipboard` / `service call clipboard` 都不可用。
- 原因：注入事件表示不了非 ASCII，且被当硬件键盘英文输入（详见 **F27**）。
- 做法：用 **yadb** 这类小程序注入（见 **F27**）。**它不装 App、不用改输入法**；
  但有个前提：**输入框必须已真正聚焦**，否则文本只进剪贴板、不进输入框。

**陷阱 4 —— 同名联系人要分清**
- 现象：按拼音搜索会同时命中相似名字的联系人。
- 做法：看清结果所在区块，点**联系人**块下的目标行；发送前再核对一次头像 / 标题。
